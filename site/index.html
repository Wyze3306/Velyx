    Comment c'est possible

    Windows voit une application différente à chaque fois.

    Bedrock est une application MSIX : Windows refuse de la lancer deux fois. Le launcher contourne ça en donnant à chaque instance sa propre identité d'application. Windows les traite alors comme des applications différentes, chacune avec son conteneur de données — et c'est ce qui lui permet de garder sa propre connexion Xbox.

    Aucun mot de passe ne passe par Velyx. Il ne stocke ni identifiants ni jetons. Dans le launcher, un compte est une étiquette posée sur une instance : la connexion se fait dans le jeu et y reste.

    Demande le mode développeur. Enregistrer une instance demande le mode développeur de Windows. Le launcher vérifie avant d'essayer, et vous dit comment l'activer.

    Le HUD

    Tout à l'écran, exactement où vous voulez.

    Dix-sept éléments à poser où bon vous semble. Prenez-en un, lâchez-le. Grille, aimantation, repères d'alignement, groupes qui se déplacent ensemble, rotation libre, opacité, verrouillage — et les flèches du clavier pour le dernier pixel. Chacun garde sa police, sa taille, ses couleurs et son fond.

      Mises à jour du jeu

      Une mise à jour de Bedrock ne casse pas tout.

      Velyx ne contient aucune adresse mémoire du jeu. Tout ce qu'il lit passe par un nom, résolu au démarrage depuis un fichier de signatures. Une nouvelle version du jeu demande un nouveau fichier, pas une nouvelle compilation. Et s'il en manque un, seule la fonction concernée s'éteint : elle le dit sur la page Diagnostic, et le jeu continue.

      Installer

      Trois étapes.

      1. 1

        Téléchargez Velyx.exe

        Un seul fichier. Le client, les polices de l'interface et les modèles de signatures sont dedans.

      2. 2

        Lancez-le

        Au premier démarrage, il dépose ce dont il a besoin dans %APPDATA%\Velyx. Rien à copier à côté, rien à installer.

      3. 3

        Créez vos instances

        Une par compte. Le launcher les construit, vérifie le mode développeur pour vous, et démarre le jeu avec le client déjà dedans.

      Pour être clair

      Aucun module ne joue à votre place : pas de killaura, pas de vol, pas de portée, pas de wallhack, aucune automatisation. Les modules d'entraînement mesurent et comptent. Et chaque module annonce ce qu'il touche : le menu affiche ces étiquettes sur la carte, avant l'interrupteur.
